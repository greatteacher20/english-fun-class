INSTALLATION
1. Back up your current English-Fun-Class folder.
2. Copy ALL contents of English-Fun-Class-Stage8 into your existing English-Fun-Class folder.
3. Choose Replace when Windows asks about duplicate files.
4. Make sure these new files are present:
   stage8.css
   stage8.js
5. Open index.html through Live Server.
6. Press Ctrl + F5.

RECOMMENDED TEACHING DEMO
My Body

Suggested 15-minute flow:
0-2 min    Hook + learning goals
2-5 min    Vocabulary + pronunciation
5-8 min    Listen and Move
8-11 min   Teacher Says / speaking
11-14 min  Mini Quiz
14-15 min  Reflection + closing

IMPORTANT
The website should support interaction, not replace the teacher.
Ask students to listen, repeat, point, move, answer, and work with a partner.
