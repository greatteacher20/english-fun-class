English Fun Class - Stage 7
Interactive English Learning for Grade 3

Created by Dedy Hendry, S.Pd. - 2026

WHAT IS NEW IN STAGE 7
- Consistent course progress across all six topics
- Progress is stored in the browser using localStorage
- Homepage shows New Topic / Continue / Completed
- Every module has Mark Topic Complete
- Previous / Home / Next Topic navigation
- Shared course.css and course.js
- Revised My Animals & Plants listening activity

HOW TO USE
1. Make a backup of your current English-Fun-Class folder.
2. Copy all files from this Stage 7 folder into your current English-Fun-Class folder.
3. Choose Replace when Windows asks about files with the same name.
4. Keep the folder structure exactly the same.
5. Open index.html with Live Server.
6. Press Ctrl + F5 once after replacing the files.

IMPORTANT
Do not delete course.css or course.js. They control the new progress and navigation system.
